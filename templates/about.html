About RaceOpt

วิธีทำงานของระบบ

RaceOpt ประมวลผลกลยุทธ์การแข่งขัน F1 จาก lap telemetry จริงทั้งเส้นทาง — ตั้งแต่ดึงข้อมูลดิบ, train โมเดลทำนายเวลาต่อรอบ, จำลองการแข่งขันทั้งกริด ไปจนถึงค้นหากลยุทธ์ทางเลือกที่เร็วกว่า

ขอบเขตของเครื่องมือ

RaceOpt เป็นแพลตฟอร์มวิเคราะห์อิสระที่จัดทำขึ้นเพื่อการศึกษา ไม่ใช่ผลิตภัณฑ์อย่างเป็นทางการ และไม่มีความเกี่ยวข้อง ไม่ได้รับการรับรอง หรือสังกัดกับ Formula 1, FIA, ทีมแข่งใดๆ หรือเครื่องหมายการค้าที่เกี่ยวข้อง ตัวเลขทั้งหมดเป็นผลจากแบบจำลองทางสถิติที่ train จากอดีต ไม่ใช่การพยากรณ์ผลการแข่งขันจริงในอนาคต และไม่ได้จำลองปัจจัยอย่างพัฒนาการของรถ, กลยุทธ์ทีมคู่แข่งแบบ real-time, หรือการตัดสินใจของนักแข่งกลางสนาม

01

Data — FastF1 lap telemetry

ต้นทางข้อมูลทั้งหมด

ทุกตัวเลขในเว็บนี้เริ่มจาก FastF1 — ไลบรารีที่ดึงข้อมูล timing/telemetry อย่างเป็นทางการของ F1 มาแปลงเป็น lap-by-lap dataset ต่อคน: เวลาต่อรอบ, เวลาแต่ละ sector, ชนิดยาง, อายุยาง, สถานะแทร็ก, สภาพอากาศ และตำแหน่งกริดสตาร์ทจริง ข้อมูลถูก cache ไว้บนดิสก์หลังดึงครั้งแรก (ดูโฟลเดอร์ cache/) เพื่อไม่ต้องยิง request ซ้ำทุกครั้งที่โหลดหน้า

02

Model — Random Forest Regressor

ทำนายเวลาต่อรอบ

โมเดล RandomForestRegressor train จาก lap telemetry จริงเพื่อทำนาย "เวลาต่อรอบ" จาก feature เช่น อายุยาง, ชนิดยาง, จำนวนน้ำมันที่เหลือโดยประมาณ, และ stint ปัจจุบัน — validate ด้วยการเทียบเวลาที่ทำนายกับเวลาจริง ของนักแข่งที่ไม่ได้อยู่ใน training set รายละเอียด hyperparameter และ feature ทั้งหมดดูได้ที่ Model Report

03

Simulation — จำลองทั้งกริด

Strategy Lab

เมื่อกำหนดกลยุทธ์ (ยาง + รอบพิท) ระบบสร้าง feature ของทุก lap ตามกลยุทธ์นั้น ให้โมเดลทำนายเวลาแต่ละรอบ บวก pace offset ที่ calibrate จากนักแข่งจริงและ pit loss ที่ประมาณจากสนามนั้น แล้วรวมเป็นเวลาทั้งการแข่งขัน — ทำพร้อมกันทั้งกริดจริงของสนามที่เลือกเพื่อจัดอันดับและคำนวณ win probability

04

Optimization — ค้นหากลยุทธ์ที่เร็วกว่า

Strategy Analysis

Grid search ไล่ชุดยาง/รอบพิทที่เป็นไปได้ทั้งหมดของสนามนั้น เทียบเวลารวมกับกลยุทธ์จริงที่นักแข่งใช้ แล้วจำแนกกลยุทธ์ที่เร็วกว่าเป็น undercut/overcut ตามรอบพิทเทียบ baseline รายละเอียดและคำอธิบายศัพท์ ดูได้ที่ Strategy Analysis
